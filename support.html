Getting started

Pointr lives in the menu bar (cursor icon) and has no Dock icon. Click the icon to turn the highlight, click ripples, spotlight and keystroke overlay on or off, and choose Settings… to change colours, sizes and shortcuts.

The keystroke overlay shows nothing

The keystroke overlay needs Input Monitoring. Open System Settings › Privacy & Security › Input Monitoring and turn on Pointr. If it still shows nothing, quit and reopen Pointr — macOS sometimes applies the permission only after a restart. If Pointr is listed but the switch has no effect, remove it with the minus button and add it again.

Passwords are not shown

That is intended. macOS does not pass keys typed into password fields or other secure input to any app.

Shortcuts

⌃⌥⌘H toggles the highlight and ⌃⌥⌘S toggles the spotlight. You can change both in Settings. If a shortcut is already used by another app, Pointr tells you.

The overlay is not in my recording

Pointr's overlays are normal on-screen windows and are captured by QuickTime, OBS, Zoom and similar apps. If a recorder is set to capture a single window only, the overlay will not be included — record the whole display instead.
